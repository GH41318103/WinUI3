# WinUI 3 Desktop UI Exploration

Modern Windows desktop UI exploration using **WinUI 3** and **C++ / C#**, focusing on native UI architecture, event-driven programming, and client-side state management as part of a broader Full-Stack engineering learning path.

##  Project Objectives
* **Modern Desktop UI**: Explore Fluent Design System components, XAML layouts, and responsive windowing in WinUI 3.
* **Client-Server Integration**: Practice connecting native desktop clients to backend REST APIs and local system services.
* **Architecture & Patterns**: Implement clean separation of concerns (e.g., MVVM pattern) and asynchronous task handling.

---

##  Tech Stack & Prerequisites
* **OS**: Windows 10 (version 1809 or higher) / Windows 11
* **IDE**: Visual Studio 2022 (with *Windows application development* workload)
* **SDK**: Windows App SDK
* **Languages**: C++ / C#, XAML

---

##  Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com
   cd WinUI3
   ```

2. **Open in Visual Studio**
   * Double-click the `.sln` solution file to open the project in Visual Studio 2022.

3. **Build & Run**
   * Select your target platform (`x64` or `ARM64`) and press `F5` to build and run the application.
